## Compatibility

The application uses library schema 6. General becomes Shared on upgrade.
Published 0.8.0 cannot read schema 6; return to an older binary only through the
[snapshot recovery procedure](../organization-and-recovery.md).
Portable backup format 1 accepts schema-6 libraries. Restore replaces the whole
library after confirmation and first creates a local recovery copy.
